# Echography Releases

Public downloads and the signed update feed for Echography, a native macOS recording and transcription app.

Requires an Apple silicon Mac running macOS 14.2 or later.

Downloads will appear under [Releases](https://github.com/natluenthaisong/Echography-Releases/releases). This repository contains no application source code, recordings, transcripts, or signing keys.

Starting with version 1.3.0, Echography can check for updates from the application menu and automatically download signed updates for installation when you quit. Preferences are in Settings → Updates.

Versions 1.2.1 and earlier require one manual installation of a newer release to gain automatic updates.
